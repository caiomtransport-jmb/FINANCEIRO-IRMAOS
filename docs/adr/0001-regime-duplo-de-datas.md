# Regime duplo de datas: caixa para o fluxo de caixa, competência para a DRE

Cada Lançamento guarda a data de competência e a data de pagamento ou recebimento. O Fluxo de Caixa usa a data de pagamento; a DRE usa a data de competência. Escolhemos isso porque o usuário precisa de fluxo de caixa real para pagar contas e de DRE por período econômico para decidir, e um regime único distorceria um dos dois. Quem vir só uma das datas em um relatório deve saber que a outra existe de propósito.
